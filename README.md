# C# Game Collection

A small collection of console mini games built with C#.

Follow these steps:

```sh
# 1. Clone the repository
git clone https://github.com/Yizune/CSharp-Game-Collection.git
cd CSharp-Game-Collection

# 2. Run the application
dotnet run
```

You need the .NET 10 SDK installed to run the project.

Alternatively, open `CSharpCollection.slnx` in Visual Studio and press the Start button.

This project is built with:

- C#
- .NET 10

It includes:

- Rock Paper Scissors
- Tic Tac Toe
- Wordle
